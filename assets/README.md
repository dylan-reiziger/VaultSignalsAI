# VaultSignalsAI logo asset

Place the original, owned VaultSignalsAI logo here as:

`VaultSignalsAI-logo.png`

The desktop app detects this PNG and uses it for the splash screen, the title-area brand mark, and the running-window icon. Rebuild the Windows package after adding or replacing the file.

For the Windows executable file icon, also provide an ICO version named `VaultSignalsAI-logo.ico`. The build configuration automatically uses it when present.

Use only artwork that the business owns or is licensed to distribute.
